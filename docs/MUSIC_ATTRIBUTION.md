# Music attribution

The application contains nine runtime MP3 cues. They are converted and edited excerpts from one source recording and are a separate asset set from the project source code.

## Required attribution

- Original composition: Franz Schubert, *Fantasia in F Minor, D. 940 (Op. posth. 103)*
- Performance: The Latsos Duo
- Live recording and Wikimedia upload: Asuas
