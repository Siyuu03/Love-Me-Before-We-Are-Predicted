# AI-use declaration

## English

Generative AI tools, including OpenAI Codex, were used as assistive tools during development of *Love Me Before We Are Predicted*. Assistance included code generation and revision, debugging, test design, technical documentation, architecture review, and iteration on visual-system parameters.

The artist directed the work, defined its concept and ethical position, selected and revised outputs, built and calibrated the physical installation, made the final artistic decisions, and remains responsible for testing and publication. AI-generated suggestions were not treated as authoritative and were accepted, changed, or rejected through human review.

The Teachable Machine classifier is a separate machine-learning component. Its output is deliberately presented as a limited and potentially misleading algorithmic gaze. It is not used to establish a participant's real gender, identity, personality, consent, compatibility, or relationship.

This repository should not be treated as evidence that generative AI, the Teachable Machine model, or its six-result mapping can make truthful claims about people.

## 中文

本项目在开发过程中使用了包括 OpenAI Codex 在内的生成式 AI 工具，协助代码编写与修订、调试、测试设计、技术文档、架构检查和视觉参数迭代。

艺术家负责作品概念、伦理立场、实体制作、现场校准、输出筛选与最终决定。AI 建议均经过人工审查，不被视为权威判断。Teachable Machine 分类器是作品中的“算法凝视”，它不能判断参与者的真实性别、身份、性格、同意、匹配度或关系事实。
