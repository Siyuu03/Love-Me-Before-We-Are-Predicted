# Documentation images

This directory contains the project's screened documentation images. The repository README currently uses:

- `Love Me Before We Are Predicted7.jpg` — physical installation view
- `Love Me Before We Are Predicted2.png` — installation interface and two camera observations

Three high-resolution PNG masters remain in the local project but are intentionally ignored because each exceeds GitHub's 100 MiB per-file limit:

- `Love Me Before We Are Predicted3.png` — 8584 × 11448, approximately 282 MiB
- `Love Me Before We Are Predicted4.png` — 8584 × 11448, approximately 282 MiB
- `Love Me Before We Are Predicted6.png` — 8584 × 11448, approximately 376 MiB

Do not silently recompress or replace the masters. If they are needed publicly, create separately named, colour-checked web derivatives after the artist approves their crop and compression, or adopt an explicit Git LFS policy.

Some images show identifiable participants. Screening for project relevance does not replace participant consent, photographer credit, venue permission, or copyright review. See `../PRIVACY_AND_CONSENT.md`.
